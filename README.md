# 本地商品目录采集器

完整本地 HTML 采集、结构校验、精确金额处理、去重、筛选、运行快照和 CSV/JSON 导出，含操作页面。

## 运行与验证

Node.js 22+。

```sh
npm ci
npx playwright install chromium
npm test
npm start
```

打开终端打印的地址。`PORT`、`HOST` 可显式配置；远程访问还需将 `PUBLIC_ORIGIN` 设置为浏览器访问的源地址。默认仅本机监听。

## 拆分边界

不含真实平台连接、账号、商家资料、自动发布和已有输出。采集器只能访问本服务合成页面，不能采集任意远程网站。

初始数据均为合成样例。运行后用户输入/导出属于用户自己的数据，不能随源码发布。源码采用 MIT 许可证，见 LICENSE；本目录没有携带原仓库历史。

## 2026-11-08 协作修订

- Docker默认绑定127.0.0.1；实际服务绑定与配置保持一致。
- 预览异步响应使用请求代次保护，旧结果不能覆盖新选择。

集合根目录 `verify_release.py --project external-local-catalog` 可复跑测试和包内首次使用示例；Web实际交互的浏览器证据另记。原版本测试数是历史记录，本轮以集合验证报告为准。

Docker默认只向 `127.0.0.1` 发布端口；扩大监听需在显式环境中设置 `BIND_ADDRESS`，并按真实入口设置 `PUBLIC_ORIGIN` 和访问保护。脚本不自动提供认证。
